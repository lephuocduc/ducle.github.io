# Hướng Dẫn Thay Đổi Hình Ảnh & Nhạc Nền

Vui lòng đặt các file tài nguyên vào thư mục này để thiệp cưới hiển thị hình ảnh thực tế của bạn:

1. `groom.jpg` - Ảnh đại diện của Chú Rể (khuyên dùng tỉ lệ vuông 1:1, dung lượng nhẹ)
2. `bride.jpg` - Ảnh đại diện của Cô Dâu (khuyên dùng tỉ lệ vuông 1:1)
3. `qr.png` - Ảnh mã QR chuyển khoản mừng cưới
4. `music.mp3` - File bài hát nhạc nền lãng mạn (Ví dụ: Beautiful in White, Until I Found You, ...)
5. `gallery/` - Thư mục chứa các tấm ảnh album đám cưới (photo1.jpg, photo2.jpg, ...)

*Ghi chú: Nếu chưa thay ảnh hoặc file mp3, website đã tích hợp tự động ảnh mẫu Unsplash chất lượng cao và nhạc hòa tấu bằng Web Audio API.*
